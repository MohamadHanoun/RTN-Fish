# RTN Fish V4 — guarded production subset

The 378,071-concept research database is stored independently; this small runtime JSON is **not** the complete knowledge base.

- Scope: selected populated places from GeoNames in 33 specific country-city questions plus the general Arab-city question.
- Eligible: GeoNames PPL/PPLA/PPLA2/PPLA3/PPLC, recorded population >= 100,000, geographic country code matching the exact prompt, Arabic-script name and Latin-script name.
- Excluded: candidate names colliding within the question, all names already matching an existing answer (including the conservative exclusion of legacy fuzzy matches), and any free-form dictionary/WordNet senses without a reviewed question relation.
- Matching: exact normalized aliases only. No V4 prefix, edit-distance, or semantic-similarity fallback. Existing canonical answers, score tiers, question order and selection remain unchanged.
- New eligible city answers get existing `common` level, 10 points, no bonus time. The count of existing `question.answers` is untouched, so answer quotas stay the same.
- Arabic and English input map to the same GeoNames identifier and cannot score twice.
- Full V4 remains Review for general words and unscoped concepts; this dataset is an automated source-verified **geographical subset**, not a claim that 378k concepts are all accepted answers.

Generated by `scripts/build-v4-runtime.py --db /path/to/rtn_fish_knowledge_v4.sqlite --out data/knowledge-v4-runtime.json` using the independent SQLite research pack. The on-server adapter uses no network call or database dependency.

## V4.1 editorial WordNet extension

V4.1 adds a second tiny exact-match adapter, `knowledge-v4-wordnet.js`, and
`knowledge-v4-wordnet-runtime.json`. It contains only 140 explicitly screened
bilingual concepts from three existing questions: bird, insect and musical
instrument. All are selected by `scripts/build-v4-wordnet-reviewed.py` from a
separate 1,487-row Review ledger, and only the 140 approved IDs are exported.

- Each bilingual pair maps to one WordNet concept ID; a duplicate answer in
  English and Arabic is counted once.
- Source WordNet hyponym relation establishes the expected class; Arabic and
  English labels were screened in an allowlist. A source-wide synonym/semantic
  fallback is never enabled. Source definitions alone never authorize answers.
- The game adapter rejects previously matched/fuzzy existing answers and
  conflicting new normalized labels. New pairs get 10 points and no time bonus.
- The 1,347 unpromoted review rows are not deployed, and ambiguous, uncertain,
  or already-covered labels remain inactive. Two suspect Arabic translations
  are explicitly documented and excluded.
- Open English WordNet 2024 and Arabic WordNet 4.1 are CC BY 4.0. See
  https://github.com/globalwordnet/english-wordnet and
  https://github.com/Salah-Sal/arabic-wordnet-v4 . AWN4 describes its Arabic
  translation process as AI-assisted; omitted labels remain Review.
