# RTN Fish — Arabic Gaming Party (Online)

**RTN Fish** لعبة جماعية عربية أصلية مستوحاة من فكرة تمرير السمكة قبل الانفجار. **المشروع مخصّص للعب عبر الإنترنت، وليس ملف HTML يشتغل لوحده.** لكل لاعب هاتفه أو الكمبيوتر الخاص به، ويدخل إلى الغرفة باستخدام رمز من أربعة أحرف أو رابط دعوة.

## التحديثات

- **تنوع عربي وعالمي:** أسئلة عن مدن ومأكولات من أنحاء الوطن العربي والعالم، مع الحفاظ على قسم Gaming. واجهة المستخدم تعرض كل الأعداد بالأرقام الإنجليزية 0–9.


- **329 فئة / 5,578 إجابة**، منها **92 فئة Gaming**، مثل Valorant وCS2 وMinecraft وFortnite وGTA وCoD وLoL وBrawl Stars وRoblox.
- **تخمين تلقائي متسامح:** مرادفات باللهجات، كلمات ناقصة، أخطاء إملائية وتبديل ترتيب حرفين. عند عدة احتمالات تختار اللعبة الأقرب، وإذا تعادلوا تُفضّل الإجابة الأشهر ضمن قائمة الفئة. لا تعتمد على AI خارجي أو خدمة مدفوعة. تظهر النتيجة المحتملة فور الكتابة، وتُعتمد بالضغط على إرسال.
- **هوست الغرفة:** يضبط عدد اللاعبين 2–10، القلوب 1–8، أقل زمن للانفجار 6–60 ثانية، أطول زمن 12–90 ثانية، ونوع الأسئلة: كلها، Gaming أغلب الوقت (تقريبًا 75٪)، أو Gaming فقط. يمكنه تعديل الخيارات في اللوبي قبل بداية اللعبة.
- **ندرة الكلمات (داخل اللعبة):**

  | الندرة | نقاط | مكافأة مباشرة |
  |---|---:|---|
  | كومون Common | 10 | 10 نقاط شحن |
  | أنكومون Uncommon | 20 | 20 نقطة شحن |
  | رير Rare | 35 | +3 ثوانٍ محفوظة |
  | إيبيك Epic | 55 | +5 ثوانٍ محفوظة |
  | ليجندري Legendary | 85 | +7 ثوانٍ وقلب إضافي |

  **كل 100 نقطة شحن = قلب إضافي.** الحد الأعلى للقلوب هو قلوب البداية +3 (وليس أكثر من 10 قلوب)، وأقصى رصيد وقت إضافي محفوظ هو **15 ثانية**.

- **طريقة احتساب الوقت:** مؤقت الانفجار عشوائي وسري ومشترك على جميع اللاعبين، ولا يرجع للصفر عند تمرير السمكة. ثواني المكافأة تنضاف لمؤقت **الجولة الجديدة التي يبدأها اللاعب صاحب المكافأة**، وليس لكل تمريرة، ويُستهلك رصيده وقتها.
- ندرة الكلمات **تصنيف لعب تقريبي** مبني على تنظيم الكلمات ضمن الفئات، وليست إحصائية حقيقية لعدد الناس الذين يعرفون الإجابة.

## انشر اللعبة أونلاين (Render)

1. فك ضغط ملف ZIP وارفع **جميع الملفات الموجودة داخله** إلى مستودع GitHub جديد، ويكون `package.json` في جذر المستودع.
2. ادخل [render.com](https://render.com) واختر `New` ← `Web Service` واربط مستودع GitHub.
3. اختر **Node**؛ أمر البناء `npm install`، وأمر التشغيل `npm start`، ومسار الصحة `/health`. يمكن استخدام ملف `render.yaml` الجاهز أيضًا.
4. اضغط Deploy. بعد اكتمال النشر ستحصل على رابط عام مثل `https://YOUR-SERVICE.onrender.com` (المثال ليس رابطًا فعليًا للعبة).
5. افتح الرابط، أنشئ غرفة، وشارك رابط الدعوة مع أصحابك. ينبغي أن يفتح كل لاعب الرابط على **نفس سيرفر اللعبة**.

**ملاحظة:** هذا الملف ZIP هو كود اللعبة الجاهز للنشر، **وليس لعبة منشورة بالفعل**؛ لا يوجد رابط عام قبل نشرها على استضافة. بعض خطط الاستضافة المجانية قد توقف الخدمة مؤقتًا عند عدم الاستخدام، والخدمة التي تحتفظ بالغرف بالذاكرة تفقد الغرف عند إعادة تشغيل السيرفر.

## تفاصيل تقنية

- Node.js 22، HTTP + WebSocket، بدون مكتبات npm خارجية، وبدون API أو رسوم لكل إجابة.
- السيرفر يتحقق من الأجوبة والندرة والمكافآت؛ قائمة الأجوبة الكاملة والمؤقت السري لا تُرسل إلى المتصفح.
- الغرف موجودة في ذاكرة عملية السيرفر فقط؛ استخدم **نسخة تشغيل واحدة** حتى لا ينفصل لاعبو الغرفة على نسخ مختلفة. للنسخ المتعددة أو حفظ الغرف دائمًا يلزم Redis/قاعدة بيانات.
- في النسخة الحالية، **انقطاع اتصال اللاعب يحذفه من الغرفة**، ولا يوجد استئناف تلقائي للجلسة؛ يرجى المحافظة على اتصال مستقر أثناء اللعب.
- الصحة: `GET /health`.
- فحص تكامل WebSocket والمكافآت: `npm test`.

## ملفات المشروع

- `server.js` منطق الغرف والنقاط والقلوب وتحديد الوقت.
- `transport.js` HTTP / WebSocket بدون مكتبات إضافية.
- `data/questions.js` الفئات العامة وتصنيف الندرة.
- `data/gaming.js` 86 فئة أسئلة Gaming إضافية.
- `data/world.js` فئات المدن والمأكولات والثقافات من مختلف الدول.
- `data/matcher.js` تخمين الكلمات والتصحيح اللهجي والإملائي.
- `public/` واجهة عربية للكمبيوتر والموبايل.
- `render.yaml` و`Dockerfile` إعدادات نشر جاهزة.
- `tests/integration.js` اختبار اللعب عبر اتصالين مختلفين.
